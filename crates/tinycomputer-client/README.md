# tinycomputer-client

The host-side TinyBus client for the TinyComputer contract. It depends on the
wire contract and TinyBus host SDK; it does not link the module, desktop or
browser implementation.

See [`docs/crates/tinycomputer-client/`](../../docs/crates/tinycomputer-client/README.md)
for the call model, family boundaries and confidentiality rules.
